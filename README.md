# PairWrite-SSM

PairWrite-SSM is a state space model for multimodal sentiment analysis. We are preparing the model code for release in this repository.

PairWrite-SSM 是面向多模态情感分析的状态空间模型。我们正在整理模型代码，整理完成后将在本仓库发布。
